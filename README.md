# Sistema de Restaurante

## Descripción

Este proyecto consiste en el desarrollo de un sistema de restaurante utilizando Python. 
El sistema tiene como objetivo facilitar la gestión de información relacionada con un restaurante 
y poner en práctica conocimientos de programación y manejo de datos.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- SQL Server

## Funcionalidades

- Registro y gestión de información del restaurante.
- Administración de datos.
- Consulta de información.
- Organización de los datos mediante una base de datos.
- Ejecución de operaciones mediante Python.

## Base de datos

El proyecto utiliza una base de datos para almacenar y organizar la información 
necesaria para el funcionamiento del sistema.

## Mi rol

Desarrollé el sistema utilizando Python, participé en la creación y organización 
de la base de datos y realicé la gestión del proyecto mediante GitHub.
